## Major — typescript 6.0.3 -> 7.0.2: NOT upgraded (deliberate)

Changelog read: TypeScript 7.0 is the Go-based native compiler (Project
Corsa). Since the RC, `typescript` on npm IS the native compiler; the package
no longer ships the in-process JS compiler API (no `main`, no `.` export —
only subpaths). Evidence:
- [microsoft/typescript-go ecosystem fallout](https://github.com/nrwl/nx/issues/36104)
  — "TypeScript 7.0 removed the in-process JS compiler API".
- Multiple tool breakages reported against 7.0.2 for packages that
  `import 'typescript'` (react-docgen-typescript#538, rollup-plugin-dts).

This repo's ONLY consumer of the `typescript` package is `@astrojs/check`
(powers `astro check`, half of `pnpm run verify`). Its latest release, 0.9.10
— the version installed — declares peer `typescript: ^5.0.0 || ^6.0.0`.
One-sentence verdict: TypeScript 7 removes the JS compiler API that
@astrojs/check's language server is built on, and its latest release peers
typescript at ^5||^6, so taking 7.0.2 would break the repo's own typecheck
gate. Left at 6.0.3 until @astrojs/check ships TS7 support.
